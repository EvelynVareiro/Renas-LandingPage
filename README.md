# Rena's Bar e Restaurante — versão final

Site institucional estático, responsivo e pronto para hospedagem.

## Arquivos principais
- `index.html`: estrutura e conteúdo da página.
- `js/script.js`: menu mobile, modal dos pratos, máscara de telefone, formulário para WhatsApp e configuração do LinkedIn.
- `assets/`: imagens otimizadas do restaurante, chef, pratos, galeria e eventos.

## Antes de publicar
No arquivo `js/script.js`, troque `SEU-USUARIO` na constante `LINKEDIN_DESENVOLVEDORA` pela URL real do perfil da desenvolvedora. O número do WhatsApp do Rena's já está configurado como `(12) 99653-9177`.

## Publicação
Envie todo o conteúdo desta pasta para a hospedagem, mantendo a estrutura de pastas. O projeto não exige instalação, servidor PHP ou processo de compilação.

- Alternância entre modo claro e modo escuro, com preferência salva no navegador.
